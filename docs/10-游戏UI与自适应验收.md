# 游戏 UI、自适应与自然动作修正

日期：2026-10-30。本文记录当前修正，优先于 07、09 的历史画面结论。当前状态：素材已接入，本轮浏览器检查、逐帧检查与生产构建通过；真机性能另行验收。

## 用户已确认的要求

所有可见操作图标与图片由指定接口生成；只保留内容与互动必需文字。背景铺满且不变形。坐姿鼠鼠与凳子整件生成，背景不再重复凳子；厨师与工作站保持正确的接触和前后关系。禁止整体上下、左右抽动，增加真实连续动作帧。每个场景有环境动效，每个人物有独立动作组。

## 成熟方案与选择

| 方案 | 用途与取舍 |
| --- | --- |
| picture 横竖构图＋object-fit: cover | 等比例铺满，允许裁边；不能同时承诺任意屏幕完整显示整图 |
| ResizeObserver＋统一世界坐标 | 背景、世界物件使用同一比例和偏移；操作热区另外保护安全区 |
| CSS border-image 九宫格 | 图片面板保持四角；原生表单、内容文字和读屏语义保留 |
| PixiJS NineSliceSprite | Canvas 面板的成熟对应方案；当前内容面板无需搬入 Canvas |
| PixiJS AnimatedSprite | 帧序、每帧时长、循环及完成回调；真实动作来自素材而非整体平移 |
| PixiJS ResizePlugin | 调整画布尺寸，不能单独解决构图与热点适配 |
| pixi-viewport | 用于可拖拽缩放大地图；当前固定小场景未引入 |

- https://pixijs.download/release/docs/scene.NineSliceSprite.html

### 触发和暂停

访客鼠和厨师等待9～18秒后首次触发闲暇，之后间隔12～24秒；点击即时打断闲暇，鼹鼠服务流程优先于自动动作。眨眼起始开放姿态有停留，不持续快速眨眼。松鼠先停留3.5秒、用连续姿势转身攀爬、藏到树干后约22秒再进入下一次循环。环境叶片／灯火／蒸汽使用Web Animations离散序列帧，独立起始时间，未通过程序绘制形状。

用户选择或系统启用减少动态效果时角色与环境静止，必要互动仍能更新姿态和文字；标签页隐藏时暂停，卸载释放动画、纹理与监听器。

## 2026-11-02 首页逐页修正（优先于此前环境动效要求）

首页取消单独叠加的动态柳枝／叶片和灯笼，保留背景原画；餐厅、酒吧暂不改版。松鼠须直接参考首页横竖背景的细像素纹理、光照、轮廓和景深，作为小型环境访客融入右侧植被，不能贴一个粗描边大树干在场景上。

所有未来素材生成必须明确：画布与网格尺寸、场景中的显示尺寸、像素密度、镜头／透视、光源、留白和安全区。角色还要明确待机母版、身体高度、头宽／头身比、脚底中点与基线；所有动作参考同一母版。抬手、拿道具只改变动作包围盒，不能改变身体大小。背景／图标／道具／九宫格也必须约束比例、视觉尺寸、边框厚度和风格，禁止生成时自动紧裁或随动作缩放。

跨动作验收必须比较“待机→挥手→闲暇→待机”实际像素和场景播放，不能用相同Canvas大小或文件分辨率替代。导出用身体／脚底基准对齐，不按包含尾巴、手和道具的每帧外接框居中。整组允许一次等比例规格归一；禁止逐帧缩放修饰模型变形，不合格需重做。已有成功原图的历史提示词保持原样，不倒填新约束。
