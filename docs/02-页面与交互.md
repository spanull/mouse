# 页面与交互：鼠鼠世界 V1.0

更新：2026-10-30。以用户参考原型和新版产品需求为准，旧版三入口小院、评论与回复界面不再使用。

## 1. 视觉

参考原型的像素童话氛围：圆润可爱鼠鼠、苔藓小屋、木质厨房、树洞吧台、便利贴、灯串、柔和粉色与薄荷绿，紫色用于酒吧和情绪入口。霓虹感通过灯串与饮品颜色轻量表达，不做强闪烁。

设计色板：奶油 `#fff7e7`、木棕 `#927354`、薄荷 `#739d8a`、柔粉 `#df9aa2`、淡紫 `#a79ac5`、深棕 `#5d4b3d`。主标题用粗字、字距与轻像素阴影，正文优先清晰的本地中文字体；尚未引入专用中文像素字体，后续选择有授权的字体资源。

主场景在桌面和手机都铺满视口，内容面板限制可读宽度。没有网页标题、说明、页脚、侧栏或底部导航；角落仅有生成图片的返回、角色和设置入口，场景名称只供读屏。

## 2. 场景关系

```text
鼠鼠之家
├─ 餐厅（完整场景＋图像菜单入口）
│  ├─ 菜单左右翻页 → 首次扣费 → 故事详情 → 五档评价 → 回菜单
│  └─ 厨房 → 编写与提交 → 待审核反馈 → 回餐厅／继续烹饪
├─ 树洞酒吧（鼹鼠吧台＋三个座位）
│  ├─ 心声墙 → 便利贴 → 放大阅读 → 关闭
│  └─ 酒单 → 选饮品 → 写心事 → 提交 → 鼹鼠送酒与安慰 → 回吧台
├─ 我的鼠鼠 → 五种形象＋可选身份描述 → 回家
└─ 设置 → 我的作品／用餐规则／匿名说明／演示工具
```

参考图展示的卡片菜单和三档简化评价仅供画面参考。实现以文字文档明确要求的单页菜品与五档评价为准。

## 4. 关键交互

### 之家与角色

角色待机自然眨眼；点击连贯挥手并出现问候，禁止整体跳动或平移抖动。角色选择即时保存，同一匿名 ID 的记录与金币不变。图片不可用时保留静态角色和 HTML 入口，动画失败可重试。

### 菜单与详情

- 每页一道菜，前后箭头明确禁用边界，手势以水平位移为主才触发，保留竖直滚动。
- 菜单独立简介不直接截取正文；预览不扣费。
- “开吃 · 1 金币”成功扣费后导航；失败显示原因和下一场时间。
- 已解锁按钮显示免费重看；刷新详情不重复扣费。
- 直接地址访问未解锁菜品只看预告，不能展示正文后再扣费。
- 评价五档可改选，只有当前选中一票；自己的菜不能自评。
- 厨房成功页明确待审核与奖励条件，可返回餐厅、继续烹饪、查看作品。

### 酒吧与酒单

调酒鼹鼠位于中间，左侧心声墙，右侧酒单。下方三张凳子，两个座位有鼠鼠，空位留给访客。已公开心声每 7 秒随机轮换，系统／应用减少动态效果或隐藏页面时不自动轮换。

饮品选择不计次；提交失败保留输入和选择。提交成功进入全屏服务场景，依次摇酒、倒酒、递酒、安慰。减少动态效果时直接显示送达姿态与文字。收好饮品或直接重开酒单清除本次演出状态，不重复消费。

### 心声墙与模态

便利贴摘要不限次浏览。点击放大居中模态；Escape 与关闭按钮同一路径。原生 dialog 管理焦点并隔离背景，关闭可回墙。正文支持换行与长文本折行，无回复按钮。

## 5. 表单与反馈

所有字段有可访问标签与字数提示；失败保留输入，同次重试不产生重复内容或消耗。页面链接、刷新、关闭以及点酒模态关闭时保护未提交内容。

当前浏览器同文档后退尚未完成统一草稿拦截，仍列后续项；不能把链接拦截描述成覆盖所有离开方式。默认不把未提交文字保存到长期设备存储。

空状态引导去厨房或酒单。隐藏、删除和非法地址明确说明，不能回显旧正文。审核和额度错误不使用仅颜色提示。

## 6. 动画与实现边界

- 所有可见场景、角色、操作图标、按钮、面板、便签、牌匾和道具均由指定接口生成。React/CSS 只放置可访问热区、文字、布局和播放。
- 使用 PixiJS AnimatedSprite；本轮修正以真实连续姿势替换旧 4／4／6 帧及本地位移。新动作帧数、时间和质量状态以 10 与资源清单为准。
- 每只角色独立实例，静态偏好和页面隐藏时停 ticker，卸载释放私有纹理和 ResizeObserver。
- 角色锚点与帧大小统一为新 V2 资源配置；画面切换和重试不积累画布。
- 主角与鼹鼠分别使用独立资源；安慰为固定文案，非实时聊天。

## 7. 验收视口与无障碍

320×568、390×844、430×932、844×390、768×1024、1440×900、1920×1080；短屏允许场景自然滚动，不能遮挡功能按钮。点按目标尽量不少于 44px。长故事、标签、便签不产生横向滚动。读屏名称和键盘焦点覆盖所有入口，原生表单保留选择、输入和屏幕阅读能力。不开启自动声音。

## 8. 场景组装与互动约束

酒吧客鼠必须连同凳子整件放置；背景不含凳子。第三张空凳是独立图片。厨房的厨师与工作台一体，身体不被柜台任意截断。背景／世界物件使用同一 cover 坐标，操作入口独立锚定安全区。

鼹鼠支持迎客、倾听、擦杯和安慰四个图像入口，每类三句本地对白；点击鼹鼠也可轮换。摇酒必须看到连续手臂和摇壶姿势，倒酒有倾斜与回正，递酒有伸手过程，不得用一个跳跃动作替代。


### 场景与人物独立动效补充

每个场景包含独立环境动效：之家叶片／灯光／松鼠停留后爬走，餐厅灯火／植物／锅边热气，酒吧灯光／植物／客鼠活动。五鼠种分别有待机眨眼、挥手和个性闲暇动作（花枝鼠看地图、仓鼠嗑瓜子、田鼠闻花、龙猫理毛、睡鼠打哈欠）；厨师有搅拌、尝味、招呼；客鼠有眨眼与喝酒／打哈欠；鼹鼠保留八类独立动作。

环境与角色分层播放，间歇错峰，交互动作优先于自动闲暇，不进行整体抖动。减少动态效果和隐藏页面时暂停。动作素材仍全部来自指定接口，具体帧数、触发规则和验收见 [游戏UI与自适应验收](10-游戏UI与自适应验收.md)。
