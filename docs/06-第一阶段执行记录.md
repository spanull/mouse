## 1. 本次范围与选择

执行 T01、T02、T03、T05，交付可运行、可点击、可刷新恢复演示记录的原型。T00 按文档允许部分推进：采用已有 Next.js＋TypeScript 技术建议及用户明确选择的小老鼠、奶油绿小院；后端及正式素材选择不因原型开发被视为全部确认。

技术版本锁定在 package-lock.json，当前主依赖为 Next.js 16.4.3、React 19.3.1、PixiJS 8.22.0、TypeScript 5.9.3。采用直接封装 PixiJS 的方式，避免同时维护适配层和手动场景实例。

视觉色板：奶油白 `#fafbf5`、浅绿 `#f0f3e7`、草木绿 `#52734e`、深叶绿 `#344734`、木色 `#ab885a` 和便签米黄 `#f3efdc`。根据用户最新要求，首页改为整屏游戏小院，仅展示小老鼠、场景物件和木质提示牌；移除桌面侧栏、页头导航、手机底部导航和首页信息流。正文采用本地中文字体，通过木框羊皮纸告示板打开。样式集中在全局样式表，正式组件扩展时可再拆为 CSS Modules。

## 4. 当前限制

- 这是演示原型，不具备真实数据库、匿名 Cookie 会话、服务端权限隔离、CSRF 防护、共享限流或管理员认证；相关验收只能在 T06～T09 接入后确认。
- 内容与通知均为虚构种子及当前访客的本地操作，关闭标签页后不保证保留。不同标签页不是可真实互通的社区。
- 未提交表单通过页面链接离开和刷新/关闭标签页时有提示；浏览器同文档后退的拦截尚未实现，输入默认仅保存在当前页面内存。
- 已完成 Chromium 自动化验证，尚未在 iOS Safari、Android 真机、虚拟键盘和低性能设备上验证；性能预算中的体积可检查，但帧率和真实设备体验尚需后续测量。
- 占位 PNG 可复现导出，但并非 GPT Image 输出。当前工具列表未提供可直接调用的内置图片生成工具，命令行和常见安装目录也未定位到 Aseprite；使用其他安装路径或生成渠道需在 T04 确认。
- `assets:placeholder` 仅用于当前占位资源；正式美术建立后应改用 T04 的导出工具，避免覆盖正式清单。
- 全量生产验收 AC01～AC12 尚未完成；此次通过的是原型层对应流程，不能据此宣布上线。
