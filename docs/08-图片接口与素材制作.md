# 图片接口与素材制作

更新于 2026-10-30。用户确认直接调用 AI Coding Gateway，不依赖已删除的 gateway-image 技能。服务地址为 `https://aicoding.aideb.me`，当前模型固定使用 **`gpt-image-2.5`**。

## 1. 已验证与当前任务

- `gpt-image-2.5`、`1024x1024`、`medium` 文生图已实测成功，生成了戴太空头盔的猫。
- 请求尺寸不能代替结果检查；下载后读取实际像素尺寸，并按目标资源尺寸处理。
- `/v1/images/generations` 携带 `image` 已在本轮 11 组素材生成中实测成功。`/v1/images/edits` 参数来自用户提供的接口说明，尚未单独实测。记录实际调用路径，不将文生图成功视为所有编辑能力已经验证。
- 当前素材替换以用户提供的鼠鼠产品原型为风格依据：细腻像素、暖棕轮廓、苔藓小屋、圆润鼠鼠、奶油粉／鼠尾草绿／淡紫。参考图只作为生成参考，不裁切为运行素材。
- 保持鼠鼠之家、餐厅、酒吧、五种访客和原创调酒鼹鼠的功能与身份。运行资源为三场景、六角色的静态及动作图片、六菜碟和四杯饮品。

## 2. 接口与鉴权

| 项目 | 值 |
| --- | --- |
| 生图 | `POST /v1/images/generations` |
| 修改参考图 | `POST /v1/images/edits` |
| 参考图生图的另一入口 | `/v1/images/generations` 同样支持携带 `image`，按用户接口说明 |
| 请求类型 | `Content-Type: application/json` |
| 鉴权 | `Authorization: Bearer $GATEWAY_API_KEY` |
| 返回 | `data[].b64_json`，必须解码到文件 |
| 请求限制 | JSON 最大 10 MB；不使用 multipart 文件上传 |
| 单请求超时 | 300 秒 |

密钥只放入制作进程的 `GATEWAY_API_KEY` 环境变量，不放进代码、文档、前端、图片清单或公开目录。项目启动和访客交互不调用生图接口。

## 3. 请求参数

下表除本轮实测结果外均依据用户提供的网关截图，不等同于 OpenAI 官方接口规格；实际可用性由网关路由和当前密钥权限决定。

| 参数 | 说明 |
| --- | --- |
| `model` | 当前选用 `gpt-image-2.5`。截图默认 `gpt-image-2`、另列 `gpt-image-1-mini`，不因此自动切换模型 |
| `prompt` | 必填，最长 4000 字；编辑时写明改变部分和必须保留部分 |
| `image` | 最多 5 张参考图组成的数组，每项为 data URL 或公网 HTTP(S) 图片链接；截图另说明兼容 `images` 数组中带 `image_url` 的写法，本项目统一用 `image` |
| `size` | `1024x1024`、`1536x1024`、`1024x1536`、`1792x1024`、`2048x2048`、`2560x1440`、`3840x2160`、`auto` 或自定义尺寸 |
| `quality` | `low` / `medium` / `high`，默认制作采用 `medium` |
| `background` | `transparent` / `opaque` / `auto`；透明需 PNG 或 WebP，仍要检查真实 Alpha |
| `output_format` | `png`（默认）/ `jpeg` / `webp` |
| `output_compression` | 0～100，只对 JPEG / WebP 有效 |
| `n` | 图片数量，默认 1。不同素材用独立请求并行制作 |

## 4. 单张生图示例

先在当前终端设置 `GATEWAY_API_KEY`。以下为 Bash 命令，Windows PowerShell 将 `curl` 写为 `curl.exe`，多行续行改用反引号，或直接使用第 6 节的跨平台 Python 制作入口。

创建 UTF-8 无 BOM 的 `generate.json`：

```json
{
  "model": "gpt-image-2.5",
  "prompt": "A cute cat wearing a space helmet, digital art",
  "size": "1024x1024",
  "quality": "medium",
  "output_format": "png",
  "n": 1
}
```

```bash
curl -sS -m 300 -X POST "https://aicoding.aideb.me/v1/images/generations" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $GATEWAY_API_KEY" \
  --data-binary @generate.json -o result.json
```

`result.json` 留在本地，禁止把整份响应、参考图 data URL 或 base64 输出到聊天、日志或模型上下文。

## 5. 修改图片示例

在 `input.png` 所在目录执行下面的 Python 片段，可在 Windows、macOS、Linux 使用。PNG 示例保留用户给出的编辑意图；实际素材任务须替换为对应提示词。

```python
import base64
import json
from pathlib import Path

body = {
    "model": "gpt-image-2.5",
    "prompt": "把背景换成海边日落，人物和衣服保持不变",
    "image": ["data:image/png;base64," + base64.b64encode(Path("input.png").read_bytes()).decode("ascii")],
    "size": "1024x1024",
    "quality": "medium",
    "output_format": "png"
}
Path("edit.json").write_text(json.dumps(body, ensure_ascii=False), encoding="utf-8")
```

```bash
curl -sS -m 300 -X POST "https://aicoding.aideb.me/v1/images/edits" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $GATEWAY_API_KEY" \
  --data-binary @edit.json -o result.json
```

用 Python 读取本地响应、检查错误并解码，文件扩展名依据魔术字节确定：

```python
import base64
import json
from pathlib import Path

result = json.loads(Path("result.json").read_text(encoding="utf-8"))
if not result.get("data"):
    error = {key: result[key] for key in ("error", "code", "message", "detail") if key in result}
    raise SystemExit(json.dumps(error, ensure_ascii=False))
for index, item in enumerate(result["data"]):
    raw = base64.b64decode(item["b64_json"], validate=True)
    ext = "png" if raw.startswith(b"\x89PNG") else "jpg" if raw.startswith(b"\xff\xd8") else "webp" if raw[:4] == b"RIFF" and raw[8:12] == b"WEBP" else None
    if ext is None:
        raise SystemExit("返回内容不是受支持的图片")
    path = Path(f"output-{index}.{ext}")
    path.write_bytes(raw)
    print(path)
```

## 6. 并行、重试与质量闭环

用户已明确确认：**多个素材同时制作；失败后立即重试，不额外等待；每次失败反馈错误原文；质量检查不通过则修改后重新生成，全部通过才结束。**

1. 默认最多 4 项素材并发，每项只有一个在途请求，互不等待成功；命令支持 `--workers` 调整并发数。
2. 接口失败立即对同项重试，反馈素材名、尝试次数及接口错误原文；没有接口错误信息时报告真实的解析／网络错误，不猜原因。不输出密钥或 base64。
3. API 成功仅表示收到图片；先保存原图及元数据，再检查风格、构图、角色一致性、完整边界、网格、透明背景和实际尺寸。
4. 图片质量不合格时保留问题记录、调整提示词并另存新版本重新请求；不能将重复请求同样提示词当作已经修正质量问题。仅通过检查的版本接入页面。
5. 本地写盘失败不重复购买图片；先解决磁盘问题。无须重复付费的裁切、尺寸统一、色键去背景和帧对齐在本地完成。
6. 已成功生成的文件可恢复使用；脚本跳过已有成功记录，但该记录不代表视觉质量通过。视觉结论另写制作记录。
7. 成功落盘后停止该项接口重试；不因缩略图、动画验证或文档编写重复生成已经通过的版本。用户中止时停止任务。

项目入口（Python 标准库＋curl）：

```powershell
python scripts/generate-gateway-assets.py --workers 4
# 仅重做指定任务：先另存该项旧原图和 JSON，修改提示词，再运行指定资源。
python scripts/generate-gateway-assets.py --workers 4 home restaurant bar rat
```

原图及提示词：`art-source/generated/`；风格参考：`art-source/reference/user-prototype.png`；最终运行图：`public/assets/world/`；来源及动画配置：`assets-manifest.json`。脚本通过 curl stdout 管道读取响应并直接落盘，不打印图片编码。

## 7. 实际错误记录

此前使用 `gpt-image-2` 返回：

```json
{"error":{"message":"Image model \"gpt-image-2\" not found. Create a virtual model with model_type=image or configure a model route first.","type":"invalid_request_error"}}
```

此前使用 `nanobanana-pro` 返回：

```json
{"code":403,"message":"API key does not have permission to access this model"}
```

旧解码代码曾因未处理无 `data` 的错误响应触发 `KeyError: 'data'`，这是客户端异常，不能当作新的服务端错误。当前入口先检查接口错误再解码。切换 `gpt-image-2.5` 后太空猫首请求成功；后续每项真实尝试次数记录在素材 JSON。
