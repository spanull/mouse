# 鼠鼠世界：餐厅与树洞酒吧 H5

一个以鼠鼠身份进入的匿名情绪游乐场。首页是鼠鼠的家：饿了去餐厅品尝故事，累了到树洞酒吧写下心事。依据用户提供的 V1.0 文档与参考原型完成本轮改版。

## 当前可体验

- 鼠鼠之家：自然眨眼、挥手和各鼠种专属闲暇动作，两家店铺入口；叶片、灯光及松鼠来访。
- 餐厅：每页一道菜，左右滑动／按钮翻页，辣度与盐味标签，首次扣费解锁正文，五档评价。
- 厨房：编写菜名、简介和故事，审核通过获得金币及加餐券。
- 酒吧：鼹鼠八类独立动作、坐姿客鼠连凳、公开心声气泡、四款饮品、写心事、完整调酒与安慰。
- 心声墙：便利贴无限浏览，点击放大；无评论和回复。
- 五种鼠鼠形象、自愿身份描述、自己的作品、设置和本地演示审核。

主页面保持游戏场景，不再使用原来的话题评论、留言回复或回复信箱。

## 启动与验证

Node.js 20.9+，当前验证环境 Node.js 24.22.1。

```powershell
npm ci
npm run dev
```

打开 [本地鼠鼠之家](http://127.0.0.1:3000/)。不需要数据库或图片服务密钥。

| 命令 | 用途 |
| --- | --- |
| `npm run typecheck` | TypeScript 检查 |
| `npm test` | 金币、餐次、点酒、奖励、评价与输入规则测试 |
| `npx playwright install chromium` | 安装浏览器测试环境 |
| `npm run test:e2e` | 双店流程、角色、响应式与降级测试 |
| `npm run build` / `npm start` | 生产模式构建与运行 |
| `python scripts/generate-gateway-assets.py --workers 4` | 开发期并行生成素材，需要环境变量 GATEWAY_API_KEY；成功项自动跳过 |
| `node scripts/prepare-gateway-assets.mjs` | 从已有原图去背景、切帧并导出运行图；导出后需视觉复验 |
| `node scripts/prepare-game-ui.mjs` | 从接口原图导出图标、面板与入口皮肤；旧动作已由natural取代 |
| `node scripts/prepare-natural-assets.mjs` | 导出自然角色、家具一体、环境动画与运行清单；重新导出后必须复验 |

## 体验审核和奖励

1. 进入餐厅点菜，每次首次品尝消耗 1 金币。
2. 去厨房写一个鼠鼠故事，提交后处于待审核。
3. 从设置 → 试玩工具与素材说明 → 演示审核台（`/admin`）通过菜品。
4. 返回餐厅，可见奖励的 1 金币及 1 张加餐券；每份菜品只奖励一次。
5. 酒吧选择饮品并写心事，成功提交才消费一杯，随后展示送酒场景。
6. 在设置查看自己的作品、减少动态效果、模拟提交失败或恢复数据。

北京时间每日金币重置为 9，00:00–11:59／12:00–17:59／18:00–23:59 各有 3 次基础品尝。基础用完再用加餐券，重看免费。加餐券和已解锁菜品跨日保留。酒吧每日免费 3 杯，心声墙不限次。

## 真实边界

当前是本地演示，不是已上线社区。数据保存在本标签页 `sessionStorage` 的 `mouse-world-v2` 键；刷新可恢复，关闭标签页后不保证保留。旧 `mouse-demo-v1` 保留但不迁移。客户端配额和正文解锁不构成安全保护。

没有真实数据库、共享内容、服务端匿名会话、管理员认证或 AI 审核。演示审核台公开可访问，举报只保存本地；当前只有基本字段和明显联系方式检查。正式版必须接入服务端权限、事务及审核。

现行场景、角色、菜碟与饮品已由 AI Coding Gateway 的 `gpt-image-2.5` 参考原型生成，首轮共 37 张 PNG，约 1.72 MiB；后续 UI 与适配批次另有43张，自然动作修正批次导出52张；来源见 `assets-manifest.json`。原图、提示词与参考记录保存在 `art-source/`，经去背景、切帧和统一锚点接入 PixiJS。所有可见 UI 图像、图标、按钮与便签皮肤同样通过该接口生成，前端只负责文字、布局、热区和播放。历史 placeholder 不被运行页面引用；占位生成器已禁止覆盖新素材。本轮已接入坐姿客鼠连凳、厨师完整工作站与自然连续动作，以及叶片、灯火、蒸汽和松鼠来访；现行修正和验收以文档 10 为准。Aseprite 源文件及真机验证仍待后续。
