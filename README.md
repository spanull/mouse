# 像素小院：项目需求与 AI 开发指南

一个以像素角色和小院场景为入口，提供匿名话题讨论与留言板的移动端 H5。

当前交付为需求与任务文档，尚未开始实现应用。项目名称为暂定名。

## 阅读顺序

1. [产品需求](docs/01-产品需求.md)：产品目标、首版范围、匿名规则与验收标准。
2. [页面与交互](docs/02-页面与交互.md)：页面结构、场景入口、角色状态与交互反馈。
3. [技术与数据设计](docs/03-技术与数据设计.md)：建议技术栈、数据、接口、权限与部署。
4. [AI 开发任务](docs/04-AI开发任务.md)：依赖顺序、交付物、验证与完成标准。
5. [AI 提示词与素材规范](docs/05-AI提示词与素材规范.md)：素材来源、角色制作、动画接入与可复制提示词。

## 如何使用

先核对产品需求中的待确认项，再让开发 AI 阅读全部文档，按任务编号逐个实现。每个任务先阅读现有代码，给出修改方案，方案确认后再修改；每个任务完成后报告改动、验证结果与剩余问题。

没有正式美术素材时，允许先使用自制占位图推进原型。缺少后端配置时，只交付明确标注的演示模式，不得将本地模拟数据描述为真实匿名社区。

所有文本文件使用 UTF-8 无 BOM；代码中的新方法需有详细中文注释。以项目实际存在的 AGENTS.md 和用户最新指令为准。

## 当前决策状态

- 已明确：像素角色、待机动画、点击反馈、匿名吃瓜、留言板，以及用 AI 协助制作。
- 素材方案已明确：以 GPT Image 为主要素材来源，开发阶段提前生成并修整；用户访问页面时不调用图片生成服务。
- 素材生产采用“GPT Image → Aseprite 修整与制作动作 → 自动导出 PNG 和配置 → PixiJS 播放”的流程。Aseprite 为首选工具，使用前检查安装和许可；LibreSprite、Piskel 为备选，图集打包工具按规模引入，详见素材规范第 3 节。
- 动画方案已明确：PixiJS 渲染小院与角色，通过 AnimatedSprite 播放精灵动画；React 承载内容页面、表单与可访问按钮，CSS 处理气泡和简单页面效果。
- 文档采用的建议基线：普通 H5 页面承载像素场景，不引入完整游戏引擎；首版文本内容优先。
- 尚需确认：吃瓜内容来源、匿名身份方式、发布审核规则、角色形象与美术风格、图片生成渠道与预算和部署预算。
- 除已明确的 React＋PixiJS 动画方案外，其余技术选型和容量限制仍为建议值，不代表用户已经选择具体服务商。
